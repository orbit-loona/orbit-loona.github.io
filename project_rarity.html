This tool is intended for my personal use, but since I posted it on the open web for my remote access, I should at least warn people who stumble upon it.

This constructs JS definitions for rarity classes; from these, this page's code can generate CSS. It is, in some regard, designed for the CSS to be compiled manually into a file. The main thing it asks for is the color scheme, because that's the main thing that makes each rarity different. At minimum, you should fill out the "Main colors" section; the "Other colors" section allows you to manually change/override some things if you want; some of the things it specifies matter in original-game and existing injected rarities (it can get complicated).

Making rarities here will not add them to the game, and will not create a script to inject them in. It will output a line of JS in the format this tool uses to define a rarity's properties (which are mostly colors. It needs to be coded into the page to be recognized. You can't do that, but if you want to make a rarity, please provide me with the resulting JS, lines of which should appear in the box below as you preview the rarities you make, by clicking "Try the rarity specified by the options". Each time you click that, it generates a new definition, so just backspace the old versions of the rarity class. (It is an editable text field, so don't accidentally delete them. Copy and paste them into a text file or other document for safe-keeping)
